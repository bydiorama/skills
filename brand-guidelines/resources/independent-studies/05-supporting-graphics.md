# Independent Study 5: Supporting Graphics
## Icons, Patterns, Illustrations, Visual Elements

*Analysis of 180 brand guideline documents (36 Diorama, 144 External)*

---

## 1. Prevalence -- What Percentage of Documents Include Graphics Beyond the Logo?

Of the 180 documents surveyed, **approximately 65% (117 documents)** include some form of supporting graphics beyond the logo. The breakdown by type:

| Graphic Type | Documents | % of Total | Notes |
|---|---|---|---|
| **Graphic devices** (named shapes, frames, overlays) | ~55 | 32% | Most common category; ranges from simple color blocks to precisely specified systems |
| **Patterns** (repeating, tiling, texture) | ~40 | 24% | Includes logo-derived, standalone geometric, and generative patterns |
| **Icon/pictogram sets** | ~35 | 21% | Custom sets range from 6 to 40+ icons; some use public libraries (BoxIcons, Google Material Symbols) |
| **Illustrations** | ~25 | 15% | Most often a style direction rather than a complete system; some include full libraries |
| **None / Not addressed** | ~60 | 35% | Particularly common in logo-only guides, quickstart documents, and TOV-only supplements |

**Diorama vs. External split:** Diorama documents skew higher in supporting graphics coverage (~78%, 28 of 36), reflecting their nature as complete brand systems. External documents vary more widely, from single-page logo guides to 200+ page comprehensive systems.

**Key finding:** The presence of supporting graphics correlates strongly with document length. Documents under 20 pages almost never include a graphic system. Documents over 40 pages almost always do.

## 2. Icon Systems

### Prevalence

Approximately 35 documents (~21%) include a formal icon or pictogram system. Custom icon sets appear in roughly half of those; the remainder reference or adapt existing libraries.

### Styles Observed

| Style | Examples | Frequency |
|---|---|---|
| **Line/outline** | Rajska 5 (stencil-break icons), NORDIKA (24x24 grid, sharp corners), REMPO (thin-line with rounded terminals), Corvus Atrium (36x36 grid) | Most common (~60% of icon sets) |
| **Filled/solid** | NOVEBA/BoxIcons (solid geometric), HSBC (app icon system), Edwin Castillo (8 category icons derived from logo mark) | ~25% of icon sets |
| **Flavour/thematic** | Tramways Coffee (9 flavour icons from coffee wheel + brewing method star-stickers + informational stickers) | Emerging niche (~5%) |
| **Duotone/gradient** | Hometree (gradient flowing-line + solid-line dual system) | Rare (~5%) |
| **Isometric/3D** | PROSIGHT (isometric illustration-style icons) | Rare but emerging |
| **Dotted/constructive** | LUCRON (icons rendered entirely from dots, echoing the brand's dot motif) | Unique example |

### Consistency Rules

The most rigorous icon systems specify:
- **Grid system:** Corvus Atrium (36x36 grid, 2-square stroke width), NORDIKA (24x24 grid), Kia (matching logo aesthetic)
- **Stroke properties:** Corner treatment (sharp vs. rounded), cap style (flat vs. round), consistent weight
- **Derivation from brand DNA:** SHARK (lambda symbol rotated/flipped into navigation icons), LUCRON (dot-at-intersection motif echoes the brand pattern), Kia (diagonal/curved lines echo logo geometry), Rajska 5 (stencil breaks matching the Macan Stencil logotype), Edwin Castillo (8 category icons derived directly from the logo mark), Tramways Coffee (icons derived from the coffee flavour wheel)
- **Color rules:** Primary vs. inverted versions, background-specific treatments

### Custom vs. Library

| Approach | Examples | Trade-off |
|---|---|---|
| **Fully custom set** | Vratna (40 pictograms), Rajska 5, CORWIN (6 principle symbols), Kia (25 pictograms + 25 UI icons), IOC (sports pictograms for all Olympic disciplines) | Maximum brand alignment; highest production cost |
| **Adapted library** | NOVEBA (BoxIcons), Howden (Google Material Symbols) | Fast deployment; less ownable |
| **Logo-derived** | SHARK (lambda transformations), PROSIGHT (LightGuide variants), Edwin Castillo (E087, 8 category icons from logo mark) | Strong brand connection; limited scope |
| **Thematic/product-derived** | Tramways Coffee (E083, 9 flavour icons from coffee wheel + brewing method star-stickers) | Product expertise embodied in iconography |

### Notable: Vratna's 40-Pictogram System

Vratna (D017) stands out with 40 custom pictograms covering nature, activities, facilities, services, infrastructure, amenities, and even local fauna. Available in standard and inverted versions, they function as a complete wayfinding language for a ski resort -- from "Ratrak with rope" to "Lepeniak" (a local creature/mascot). This is the most extensive icon set in the Diorama portfolio.

## 3. Pattern Systems

### Three Origin Categories

**A. Logo-derived patterns (~50% of pattern systems)**

The most common approach: extracting shapes, strokes, or structural elements from the logo to create repeating or compositional patterns.

| Brand | Derivation Method |
|---|---|
| **DEUS** (D006) | Trapezoid symbol outline multiplied, rotated, and scaled; tiled grid variant |
| **Queens 2015** (D034) | Q descender stroke as standalone motif in 4 variants (original, exploded, section, aligned) |
| **Workin** (D036) | W letterform multiplied on square grid, alternating 90-degree rotation |
| **KALW** (E118) | Each of 26 alphabet letters in the custom stencil font generates a unique pattern template -- the most original pattern system in the collection |
| **KBT** (D032) | Geometric shapes with carved-out interiors, derived from stone-cutting metaphor |
| **Research Ireland** (E141) | Logomark grid generates squares and circles used for patterns, icons, frames, and overlays |
| **Detroit Institute of Arts** (E023) | Golden rectangle subdivisions create a shape vocabulary of half-circles, spirals, squares |
| **Oktawave** (E024) | Binary encoding of brand name letters into visual 1/0 strip patterns |
| **ASICS** (E147) | Pattern Grid derived from brand elements |
| **KOYOK** (E079) | Geometric forms derived from the Brazilian flag (circle/square/triangle), 4 variants per shape, combined into patterns with grain texture |
| **Motorola** (E012) | Dedicated pattern section (p.55+) |

**B. Standalone patterns (~30%)**

Patterns designed independently of the logo, often based on geometric grids or brand-relevant metaphors.

| Brand | Pattern Description |
|---|---|
| **SHARK** (D002) | Square mosaic subdivision system -- surfaces divided into 4, then 16 parts, with tint fills and optional perforation (white omissions). Applied to print (die-cutting), interiors, and installations |
| **LUCRON** (D005) | Dot pattern built from 6 base grid modules (dense, scattered, sparse, vertical bar, diagonal, horizontal bar). Modules combined into larger compositions; accent dots in secondary palette colors |
| **Kolinska Distrikt** (D021) | 10 unique label shapes derived from architectural landmarks; used as standalone elements, cropped background frames, or sticker/CTA containers |
| **Corvus Atrium** (D025) | Repeating nest elements as dividers; always bleeds off edges; minimum 2 rows, maximum 4 rows |
| **MICA** (E002) | Dual system: Organic pattern (with shadow variant) and Linear pattern (with logo integration) |
| **Stella Artois** (E041) | Dedicated pattern system within the Kit-of-Parts framework |
| **Umbro** (E106) | Heritage-pattern system |

**C. Generative/algorithmic patterns (~10%)**

The rarest and most sophisticated category. See Section 6 for detailed analysis.

### Notable Examples

**FONA Light Patterns (D003):** The gold standard in the collection. Mathematically constructed curve systems built on golden-ratio proportions. Curves evolve from one form to another in equidistant steps (12, 14, 16, or 20). Each pattern variant is defined by 5 parameters: rotation (0/45/90/135 degrees), line colour, opacity, crop percentage, and number of steps. Eight documented variants across 11 pages. The guidelines call these "the most essential part of the new FONA visual identity."

**KBT Blox (D032):** A bespoke variable typeface with only 3 letters (K, B, T) and numbers in 6 weight/slant variants. The Block-Raw-Sculpt progression is a conceptual metaphor for the stone-processing industry. While technically typography, it functions as a generative graphic system -- each weight represents a stage of material transformation.

**Kolinska Distrikt Labels (D021):** Ten label shapes derived from architectural site studies. Each shape is usable in three modes: standalone element, cropped background frame, or sticker/CTA container. The system is paired with large decorative quotation marks filled with a mosaic/checkered pattern. Kolinska demonstrates how a well-developed shape library can replace traditional patterns.

## 4. Illustration Styles

### Spectrum of Approaches

| Approach | Prevalence | Examples |
|---|---|---|
| **No illustration** | ~70% | Most documents rely on photography and/or graphic devices |
| **Style direction only** | ~15% | Guidelines specify illustration characteristics without providing a full library |
| **Custom illustration library** | ~10% | Full sets of illustrations with usage rules |
| **3D renders replacing illustration** | ~5% | Emerging trend using 3D compositions as brand imagery |

### Photographic vs. Illustrative vs. Abstract

**Illustrative (hand-drawn/digital):**
- **Titans** (D019): Semi-realistic comic-book style character illustrations for brand archetypes. Three characters (Hero-Warrior, Guardian-Caregiver, Explorer-Futurist) in the brand colour palette. Unusual for IT staffing.
- **NOVEBA** (D033): Line-drawn, digitally sketched, black-and-white illustrations that "convey energy of naturalness and humanity." Animated variants with 24+ fps, fluid transitions.
- **Oyster** (E066): Custom library by Maria Milenko (Hugman Studio) -- loose, handmade lines emphasizing diversity and inclusion. Named illustrator is unusual.
- **Burger King** (E135): Four illustration categories (Storytelling, Stripes, Typography, Iconography). Bold, organic, food-centric; described as "mouthwatering."
- **Lunchbox** (E117): 14-page illustration section plus separate "Abstractions" and "Lettering & Icons" sections -- one of the most comprehensive illustration systems.
- **Slack** (E071): Illustrations that "reflect Slack personality: human, approachable, smart. Can be witty but never silly."
- **IOC** (E070): Concept-driven illustration system with style/colour guidance, illustration types, combining rules, cropping rules, and an indexed library.

**Abstract/geometric:**
- **Byteminds** (D027): Two primitive shapes (square and circle) scale from logo icon to full-page 3D compositions. Spheres and cubes in brand colours with dramatic lighting replace photography entirely.
- **George Hillary** (D022): Halftone/stippled mountain ridge illustration -- editorial vintage-adventure aesthetic.

**3D renders and fabrication as emerging trend:**
- **Byteminds** (D027): 3D library of sphere + cube scenes used as hero imagery. The brand has no traditional photography at all -- 3D compositions serve every visual role.
- **Wave** (E064): AI-generated glass wave sculptures created via Midjourney prompts. The brand includes specific Midjourney prompts and maintains a database of AI-generated images as official brand assets. This is the most forward-looking approach in the collection.
- **NORDIKA** (D018): Realistic architectural 3D renders serve as the primary photographic content; renders that include people are preferred.
- **Network Rail** (E084): 3D fabrication guidelines for physical signage, with low-fidelity dot-matrix variants at 5 sizes down to 8x8px. Demonstrates the rare intersection of digital-grid thinking and physical brand production.

**Mascots and character elements:**
- **Edwin Castillo** (E087): Motty the Monkey mascot integrated with confetti element and 8 category icons -- a full character-driven graphic ecosystem.
- **Tramways Coffee** (E083): Warm/cool sticker pairing system with brewing method star-stickers functioning as both decorative and informational elements. The sticker system acts as a secondary graphic language alongside the icon set.

## 5. Graphic Devices -- Named Branded Elements

The most strategically significant category. Named graphic devices transform abstract shapes into proprietary brand assets. The best examples invest as much specification in these elements as in the logo itself.

### Tier 1: Fully Theorized Graphic Devices

These are not just shapes -- they come with names, construction rules, metaphorical rationale, and extensive application guidelines.

| Brand | Device Name | Description |
|---|---|---|
| **Sony** (E097) | **The Open Frame** | A bordered frame area where "product and message slide onto the page seamlessly." Mathematical construction: top bar 4.35h, left bar 4.35h, bottom bar 5h (where h = logo height). Metaphorical connection to Sony products that are themselves frames (VAIO frames interface, Cyber-shot frames pictures, BRAVIA is a frame). Differentiation argument: "Most communication from competition uses full-bleed page layouts." |
| **Hulu** (E091) | **The Vessel** | Central design element "born from the name and logo, core to the design system." Integrates across illustration, iconography, grids, product design, and motion toolkit. |
| **RAC** (E015) | **The Chevron** | 8 dedicated sub-sections covering definition, usage, formatting, logo relationship, reverse side, digital display, OptinMonster, and social media. A separate device called "The Tag" exists for branded photography. |
| **PROSIGHT** (D023) | **The LightBox / LightGuide** | Spark symbol inside a neon green rounded container. Serves 6 functions: photo frame, content highlight, information carrier, CTA container, tag element, and layout anchor. Construction: 13x13 grid, star offset = 3x (where x = 1/5 wordmark height), corner rounding never greater than 15.38% of total height. |
| **Docusign** (E074) | **The Shape of Agreements** | Dog-eared document shape (45-degree fold). Combined with glassmorphism (frosted glass effect) and intersecting geometric shapes representing "agreements coming together." |
| **NatGeo** (E104) | **The Index** | A perpetual-motion data graphic that moves along the X axis, never stops, only slows down. Macro and micro data units contextual to content (atmospheric density, nautical miles, temperatures). Reinforces the "Further" brand concept through forward-only motion. |

### Tier 2: Well-Specified Graphic Devices

| Brand | Device | Description |
|---|---|---|
| **Corvus Atrium** (D025) | **The Nest** | Circular/nest form used 7 ways: full-width aligned to margins, centered at bottom, framing round photos, visualizing travel times as a clock dial (dark segment = travel time), stickers, URLs, and repeating divider patterns. |
| **REMPO** (D009) | **Framing Device (Oramovanie)** | Border line deformed in stroke weight and corner radii. Can be rendered in single/combined colours, split by area, or filled with photography. May overlap or extend beyond format edges. |
| **Brickline** (E062) | **Content Frames + Connecting Brick** | Image treatment with logo cut from corners (max 2 corners per frame). Brick graphic in 3 modes: pattern, imagery carousel, mixed use. Animation principles: "brick by brick" emergence. |
| **92NY** (E057) | **The Logo Band** | Systematic framing element across all applications. |
| **Crafts Council** (E137) | **Two Overlapping Circles** | One from the logo position (top-left), one from bottom-left corner; circles scaled until they touch. 4-step geometric construction method; adapts to landscape and portrait formats. |
| **Tupperware** (E125) | **Container Silhouette** | Iconic Tupperware shape (47.5/42.5 degree rounded corners) used as framing/storytelling device. Holds imagery, text, Big T, infographics, page numbers, CTAs. |
| **Howden** (E067) | **Logo Crops** | Portions of the logo used as large-scale graphic device on covers, with tint and contrast variations. |
| **Kia** (E069) | **Three Graphic Motif Types** (A, B, C) | Derived from logo geometry with mathematical placement rules (percentage margins, anchor ranges, radius equations). Must not "descend downwards" -- consistent rising energy. |
| **Havas** (E086) | **Four Graphic Styles from "h"** | 4 graphic treatments derived from the "h" logo (Solid/Vertical Line/Horizontal Line/Outline). 3D dimensional expression encouraged with local cultural adaptation per office. |
| **Wave Essence** (E089) | **The Sinusoidal Wave** | Sinusoidal wave as "constant style element" with variable amplitude and thickness. Functions as a unifying graphic thread across all applications. |

### Tier 3: Simpler Graphic Elements

| Brand | Element |
|---|---|
| **Generali Balans** (D004) | Horizontal colour stripes + illustrated stripe variant |
| **IN KANAL** (D031) | Pipe/channel motif derived from letterforms |
| **DSTRCT Berlin** (D007) | Oversized cropped typography as graphic composition |
| **The Shed** (E149) | Oversized cropped typography as primary graphic device, horizontal rules as structural framing |
| **Queens 2023** (D014) | Tag shapes in 4 composition scales (Exploded, Oversized, Standard, Confetti) |
| **Zip** (E116) | "Pocket" motif from overlapping letter shapes + diagonal composition |
| **Channel 4** (E025) | Logo shadow effect -- the "4" shape appears as a shadow over any content |
| **British Museum** (E098) | Circle defacer for promotional elements |
| **Whitney** (E059) | The Responsive W as grid and generative graphic device |
| **Bolt** (E081) | Lightning bolt extracted from logo letterforms |
| **Point Nine** (E148) | Comma/9 shape at various scales; logo animation showing dot growing into full form |

### How Top Brands Create Ownable Graphic Language

The pattern across the most successful examples:

1. **Name it.** The Open Frame, The Vessel, The Chevron, The Nest, The Index -- naming a shape transforms it from a design element into a brand asset.
2. **Specify it mathematically.** Sony's proportional formula (4.35h, 5h), PROSIGHT's grid construction, Kia's percentage-based placement rules.
3. **Give it a metaphorical rationale.** Sony connects framing to product DNA; Corvus ties the nest to home; Brickline's brick connects to the greenway infrastructure.
4. **Define multiple modes.** PROSIGHT's 6 functions, Corvus's 7 applications, Kolinska's 3 modes per shape.
5. **Constrain it with clear don'ts.** Kia's motifs "must not appear to descend." Corvus's nest pattern: "minimum 2 rows, maximum 4 rows; never isolated individual elements."

## 6. Generative/Algorithmic Graphics

The rarest category, found in fewer than 10% of documents. These systems define visual elements through rules and parameters rather than fixed assets.

### Mathematical/Parametric Systems

| Brand | System | Parameters |
|---|---|---|
| **FONA** (D003) | Golden-ratio light patterns | 5 parameters: rotation, line colour, opacity, crop, steps. Curves evolve in equidistant steps on a golden-ratio grid. |
| **Whitney** (E059) | Responsive W | The W is constructed through a step-by-step process; its form changes responsively based on context. Experimental Jetset's design is a landmark in generative identity. |
| **Crafts Council** (E137) | Two-circle intersection device | Mathematically defined: circles scale until they touch; position shifts based on format orientation (landscape: center moves left ~1/5 width; portrait: center moves up ~2/5 depth). |
| **Oktawave** (E024) | Binary encoding pattern | Brand name letters encoded as binary 1/0 visual strips. The pattern is computationally determined, not hand-drawn. |
| **CORWIN** (D016) | Chevron wave pattern on square grid | Each cell contains two diagonal lines. Minimum 4, expandable to 6. Must align to grid. |
| **Sony** (E097) | Open Frame proportional system | All dimensions defined as multiples of logo height (h). |
| **Kia** (E069) | Motif placement algorithm | Anchor points within 2/3A to A range, margins as percentages, radius = 0.1X. |

### AI-Generated Graphics

**Wave** (E064) includes Midjourney prompts and maintains a database of AI-generated images as official brand assets -- the only document in the collection to formally incorporate AI image generation into brand guidelines.

### Observations

Generative systems appear predominantly in two contexts:
1. **Cultural institutions** (Whitney, DIA, Crafts Council) where a single identity must accommodate diverse programming
2. **Technically sophisticated brands** (FONA, Oktawave) where algorithmic precision reinforces brand positioning

The toolkit implication is significant: generative approaches could enable a brand guidelines tool to create infinite on-brand variations from a parametric definition rather than distributing fixed asset files.

## 9. Best Examples -- Top 5 Supporting Graphics Sections

### 1. IOC Olympic Brand Guidelines (E070)
**Score: 5/5.** The most complete supporting graphics system in the collection. Field-of-play graphic devices derived from actual sport surfaces. Universal pictogram system covering all Olympic sports with clear space, minimum size, colour system, and container rules. Concept-driven illustration system with indexed library. Infographic system with chart types. All tied together by a coherent visual philosophy.

### 2. FONA Light Patterns (D003)
**Score: 5/5 for the pattern system specifically.** Golden-ratio parametric curves defined by 5 parameters across 8 documented variants. This is the most mathematically rigorous and conceptually distinctive pattern system in the collection. It elevates a dental equipment brand into design-system territory more commonly associated with technology or architecture.

### 3. Hulu's Vessel System (E091)
**Score: 5/5 for integration.** The Vessel is remarkable not for the element itself but for how thoroughly it is integrated -- spanning illustration, iconography, grids, product design, motion toolkit, campaigns, and evergreen brand. Demonstrates what happens when a graphic device is treated as seriously as the logo.

### 4. Kolinska Distrikt Label Library (D021)
**Score: 5/5 for conceptual depth.** Ten unique label shapes derived from site architecture, each usable in 3 modes. Combined with food-coded colour names, mosaic-filled quotation marks, and arch-type claims on 80%-height circles. The richest graphic vocabulary in the Diorama portfolio.

### 5. Corvus Atrium Nest System (D025)
**Score: 4.5/5.** The nest element serves 7 distinct functions, including the brilliantly original time-visualization dial (dark segment = travel time on a clock face). The repeating nest pattern has precise rules (min 2 rows, max 4, always bleeding off edges). The primary and secondary icon sets are grid-specified. A complete visual toolkit for a real estate brand.

**Honourable mentions:** Sony Open Frame (E097) for mathematical rigour and metaphorical depth; Kia (E069) for precision-engineered graphic motifs; KALW (E118) for the 26-letter generative pattern system; Whitney (E059) for the Responsive W as a generative identity landmark; SHARK (D002) for the square mosaic system.

## 10. Toolkit Implications -- What to Suggest and Generate

Based on the patterns across 180 documents, a brand guidelines toolkit should address supporting graphics at four levels:

### Level 1: Graphic Devices (Recommend for Every Brand)

Every brand should have at least one ownable graphic element beyond the logo. The toolkit should:
- **Suggest derivation from the logo** -- extract a shape, stroke, or negative space as a standalone element (as SHARK, Queens, Workin, Bolt, and Kia demonstrate)
- **Provide a naming prompt** -- encouraging clients to name their device (research shows named devices get 3-4x more application guidance in guidelines)
- **Generate construction rules** -- proportional specifications, placement rules, minimum/maximum sizing
- **Define multiple modes** -- at minimum: full element, cropped/partial, pattern repeat

### Level 2: Pattern System (Recommend for Brands with 40+ Page Guidelines)

Patterns add visual richness and are especially valuable for digital backgrounds, packaging, and environmental applications. The toolkit should offer:
- **Logo-derived pattern generator** -- automate the extraction and tiling of logo elements (the most common approach: ~50% of pattern systems)
- **Dot/grid pattern builder** -- parametric systems like LUCRON's or SHARK's mosaic, where density, colour, and perforation can be controlled
- **Opacity/tint integration** -- most pattern systems use reduced opacity or tint variations rather than full-colour elements

### Level 3: Icon System (Recommend for Brands with Wayfinding, Product, or Digital Needs)

Custom icons are worth the investment when a brand has physical spaces, product lines, or complex digital products. The toolkit should:
- **Specify a grid** (24x24 or 36x36 are the most common) and stroke properties (weight, corner treatment, cap style)
- **Enforce stylistic consistency** with the brand's typographic personality (round terminals for friendly brands, sharp corners for technical brands)
- **Provide a starter set** of 12-15 universal icons (arrow, info, close, search, menu, phone, email, location, download, share, settings, user, calendar, clock, heart)

### Level 4: Data Visualization (The Biggest Gap -- High-Impact Opportunity)

Only ~5% of documents address charts and graphs. The toolkit should fill this gap by:
- **Generating a chart style guide** that maps the brand's colour palette to data categories
- **Specifying chart typography** (axis labels, legends, callouts using the brand's type hierarchy)
- **Defining do/don't rules** for chart colours, gridlines, and decorative elements
- **Providing a contrast-checked palette** for overlapping data series

### Additional Toolkit Opportunities

| Opportunity | Rationale |
|---|---|
| **Motion specification templates** | Only 15% of brands address motion; providing easing curves, frame rates, and emergence patterns as defaults would add significant value |
| **AI-generated graphic assets** | Wave (E064) demonstrates the frontier -- Midjourney/Stable Diffusion prompts as official brand assets. A toolkit could generate prompt templates aligned with brand personality |
| **Illustration style briefs** | Rather than generating illustrations, produce structured briefs (line weight, colour palette, subject matter, emotional register) that can direct illustrators or AI tools |
| **Shape mode matrix** | For each graphic device, auto-generate a matrix showing it in: solid fill, outline, cropped, pattern repeat, photo mask, and animated states |

### Priority Matrix for Toolkit Development

| Feature | Impact | Effort | Priority |
|---|---|---|---|
| Logo-derived graphic device suggestions | High | Medium | P1 |
| Pattern generator (logo-derived + parametric) | High | Medium | P1 |
| Data visualization style guide | Very High (fills biggest gap) | Medium | P1 |
| Icon grid + starter set specification | Medium | Low | P2 |
| Motion specification templates | Medium | Low | P2 |
| Illustration style brief generator | Medium | Low | P2 |
| AI image prompt templates | Low-Medium | Low | P3 |
| Generative/parametric pattern engine | High | High | P3 |
