> Analysis of typographic systems across 180 brand guideline documents (36 Diorama, 144 external).

## 2. Type Pairing Patterns

### Pairing Strategies

The most common pairing pattern across the corpus is **sans-serif + sans-serif** (same or different families), not the traditional serif + sans-serif combination.

| Pattern | Frequency | Examples |
|---------|-----------|---------|
| **Sans + sans (different families)** | ~40% | Circular + Poppins (Corwin), Matter + -- (REMPO), Cera Stencil Pro + Cera Pro (Marina Dorcol), PP Neue Montreal + Macan Stencil (Rajska), Sans Plomb + Haffer (Vratna), Paralucent + Work Sans (DSTRCT), Field Gothic + Azeret (Kolinska), Bagoss + Saans (Noveba), All Round Gothic + Basic Gothic Pro (Tramways Coffee), Cera (5 weights) + Alte Haas Grotesk (KOYOK) |
| **Single family (different weights)** | ~30% | Haffer only (Queens 2023), Season Heavy + Medium (Corvus Atrium), CircularXX Black + Regular (Workin), Gellix Medium only (ssleek), Helvetica Neue only (Generali Balans) |
| **Serif + sans-serif** | ~15% | PP Eiko + Sofia Pro (WEM Private Fund), ITC Garamond + Helvetica (Apple 1987), Cooper BT + Sharp Grotesk (Pleo), GT Ultra + Aktiv Grotesk (Handshake), ABC Arizona Flare + sans (IMS) |
| **Display/stencil + body sans** | ~10% | Macan Stencil + Macan (PROSIGHT), Fixture Ultra only (No18), Paralucent Stencil + Work Sans (DSTRCT) |
| **Monospace or special + sans** | ~5% | OCRB + Calvert (Tate), KBT Blox + Saans (KBT) |

### Number of Typefaces per Brand

| Count | Frequency | Notes |
|-------|-----------|-------|
| **1 typeface** | ~25% | Single family across all uses; relies on weight variation for hierarchy. Examples: Queens 2023 (Haffer), Generali Balans (Helvetica Neue), ssleek (Gellix), Season (Corvus Atrium) |
| **2 typefaces** | ~55% | The dominant pattern. One for display/headings, one for body. Examples: Corwin (Circular + Poppins), WEM PF (PP Eiko + Sofia Pro), Marina Dorcol (Cera Stencil + Cera Pro), REMPO (Matter), Nordika (LL Supreme + Neue Haas Unica) |
| **3+ typefaces** | ~20% | Includes system/fallback as a distinct third tier. Examples: SHARK (Gilroy + Montserrat + Verdana), FONA (Proxima Nova + Helvetica/Arial), TECHBOX (Sequel 100 + Qanelas + Space Grotesk + Acumin), WEM (Sofia Pro + Georgia + Arial), Kolinska (Field Gothic + Azeret + Arial Narrow), PROSIGHT (Macan + Macan Stencil + Arial) |

**Key finding:** The two-typeface model dominates, but single-family systems are more common than expected (~25%). When brands use a single family, they tend to choose typefaces with wide weight ranges (6+ weights) to maintain hierarchy through weight contrast alone.

## 3. Hierarchy Systems

### Number of Levels

| Levels | Frequency | Typical Structure |
|--------|-----------|-------------------|
| **2-3 levels** | ~15% | Minimal docs (quickstarts, logo guides). Heading + Body only. |
| **4-5 levels** | ~30% | Standard. Headline, Subheadline, Body, Caption. |
| **6-7 levels** | ~35% | Most common in comprehensive guides. Display, H1-H3, Body, Caption, Overline. |
| **8-11 levels** | ~20% | Enterprise or design-system-ready docs. Full scale from Display through Footnote/Tiny. |

### How Hierarchy Is Defined

Three dominant approaches emerge for specifying type sizes:

**1. Absolute values (pt or px) -- ~45% of docs with hierarchy specs**
Most common in print-oriented or comprehensive guides. Examples:
- Marina Dorcol: Display 1 (72/80), Display 2 (64/72), Text M (16/24), Text XS (13/16)
- WEM Private Fund: Heading 1 (100/110), Body Medium (20/24), Footnote (14/18)
- Nordika: H1 (144pt), H2 (108pt), H3 (72pt), Paragraph (16pt)
- Kolinska: Headline (260px), Copy Large (72px), Copy Small (48px)
- Noveba: Heading XL (136pt), Body M (24pt), Body S (16pt)
- Gerulata: H1 (135/120), Body Large (24/32), Body Tiny (14/21)

**2. Relative/percentage-based -- ~30% of docs with hierarchy specs**
More flexible, resolution-agnostic. Examples:
- SHARK: Sequencer (900%), Headline (500%), Section (300%), Copy (100%), Caption (80%)
- Corwin: Headline (300%), Subheadline (180%), Copy Medium (100%), Copy Small (80%)
- Queens 2023: Large Headline (300%), Copy (100%), Small (80%)
- FONA: Sequencer (300%), Headline (200%), Copy (100%), Caption (80%)
- Corvus Atrium: Pre Title (600%), Headline Large (300%), Copy Large (100%), Copy Small (50%)

**3. Ratio-based (size/leading pairs without base unit) -- ~25%**
- REMPO: Display 1 (72/80), H1 (64/72), Text M (16/24), Overline (13/16)
- WEM: H1 (64/80, 1.25x), Body (16/24, 1.5x)

### Most Common Level Names

Ranked by frequency across all documents that define hierarchy levels:

1. **Headline / Heading** (appears in ~90% of hierarchy specs)
2. **Body / Copy** (~85%)
3. **Subheadline / Subheading** (~60%)
4. **Caption** (~45%)
5. **Overline** (~40%)
6. **Display** (~35%)
7. **Sequencer** (~15%, a Diorama convention)
8. **Lead** (~10%)
9. **Footnote** (~10%)
10. **Small text / Tiny** (~10%)

**"Sequencer"** is a distinctive Diorama convention appearing in SHARK, FONA, and Queens 2015 -- referring to the largest display level (often 500-900% of base). This term does not appear in any external brand guidelines.

## 4. Fallback Strategies

### How Many Docs Define Fallbacks

| Status | Count | % of corpus |
|--------|-------|-------------|
| Defines explicit fallback/system font | ~55 docs | ~32% |
| No fallback mentioned | ~115 docs | ~68% |

### Most Common Fallback Fonts

| Fallback | Appearances | Context |
|----------|------------|---------|
| **Arial** | 37 | Universal system fallback; most commonly specified alternative |
| **Helvetica** | 18 | macOS fallback, often paired with Arial for cross-platform |
| **Georgia** | 9 | Serif fallback for formal/office contexts (WEM, WEM PF, DEUS) |
| **Verdana** | 3 | Email/screen fallback (SHARK) |
| **Calibri** | 3 | Office document fallback |
| **Times New Roman** | 2 | Legacy serif fallback |
| **Poppins** | 2 | Google Fonts fallback for commercial sans-serifs (Corwin) |
| **Montserrat** | 2 | Google Fonts fallback for geometric sans (SHARK, Queens 2015) |

### Fallback Chain Patterns

The most sophisticated fallback specifications include full CSS-style chains:
- FONA: `Arial, Helvetica, sans-serif` for email signatures
- SHARK: Gilroy (primary) -> Montserrat (web) -> Verdana (system/email)
- Corwin: Circular (primary) -> Poppins (web fallback)
- DEUS: Fedra Sans Alt Pro -> Arial (with candid note that "Arial is not a craftsmanship-equal replacement")
- Kolinska: Field Gothic -> Arial Narrow; Azeret -> Arial
- Noveba: Bagoss -> Arial; Saans -> Arial
- Vratna: Sans Plomb (headlines) + Haffer (body) -> Arial (body only, never combine Haffer and Arial)

**Key finding:** Only about one-third of documents specify fallback fonts at all. Among Diorama projects, the rate is higher (~50%) because many projects explicitly plan for web/office contexts. The most mature documents define a three-tier system: primary (brand font) -> secondary (web/Google alternative) -> tertiary (system font).

## 7. Line-Height and Spacing

### Common Line-Height Values

Line-height specifications appear in approximately 60% of documents that define typographic hierarchy. The values cluster around:

| Context | Most Common Values | Range |
|---------|-------------------|-------|
| **Display / Large headlines** | 0.9-1.0 (90-100%) | 0.85-1.1 |
| **Standard headlines** | 1.0-1.1 (100-110%) | 0.95-1.25 |
| **Subheadlines** | 1.0-1.2 (100-120%) | 1.0-1.5 |
| **Body copy** | 1.2-1.5 (120-150%) | 1.1-1.6 |
| **Captions / Small text** | 1.3-1.5 (130-150%) | 1.2-1.6 |

**Conventions observed:**
- Tight line-heights (0.9-1.0) for display are a strong Diorama signature, appearing in Queens 2023, Corwin, Vratna, and Corvus Atrium
- The 1.5 value for body text is the single most common specification
- A progressive scale from tight (display) to loose (body) is the standard pattern

### Tracking / Letter-Spacing

Tracking specifications appear in about 30% of documents:

| Context | Common Values | Examples |
|---------|--------------|---------|
| **Display/Headlines** | -1% to -4% | Kolinska (-4% for headlines), Nordika (-3% for H1-H4), Corwin implicit |
| **Body text** | 0 (default) | Near-universal |
| **Overline / Caps** | +10 to +25 | Queens 2015 ("Caption headline" in caps), Rajska (Small text +20), Slack (+0 to -0.2px) |
| **Logo wordmarks** | +5% to +15% | Nordika (LL Supreme at 12%), Marina Dorcol (generous letter-spacing) |

**Key finding:** Negative tracking for headlines is increasingly common in contemporary brand guidelines, particularly in the Diorama portfolio. This reflects a broader design trend toward tightly-set display typography. Positive tracking is reserved for uppercase text and overline elements.

**Notable addition:** Ogilvy (E085) is the most typographically granular document added to the corpus -- specifying not only wordspacing but prohibiting the "gi" ligature in Ogilvy Sans, providing 3 distinct numeral sets (lining, old-style, tabular), and defining a 66-character ideal line length. This level of OpenType-feature-level specificity is unique in the corpus.

## 8. Web vs. Print Distinction

### How Many Docs Distinguish Between Digital and Print Typography

| Status | Count | % |
|--------|-------|---|
| Explicit web vs. print distinction | ~25 docs | ~15% |
| Separate digital font specification | ~15 docs | ~9% |
| No distinction (single system for all) | ~130 docs | ~76% |

### Notable Web/Print Distinctions

- **SHARK** (D002): Gilroy for print, Montserrat for web, Verdana for email. Email newsletter specs: 15px base, 18-20px headings, 30px spacing. The most thorough web/print split in the Diorama portfolio.
- **Channel 4** (E025): Bespoke C4 Text with specific point-size guidance (best at 7, 9, 10, 11, 12pt). Web body typeface called out separately.
- **RAC** (E015): Separate "Web body typeface" section (5.2) distinct from primary typeface (5.1).
- **Apple 1987** (E005): ITC Garamond at 80% condensed width for print; no digital guidance (pre-web era).
- **FONA** (D003): CSS font stack specified for email (`Arial, Helvetica, sans-serif`).
- **Slack** (E071): Specific web letter-spacing values (-1px for small headlines, -2px for large, 0px for body, -0.2px for hero).
- **Noveba** (D033): 12-column grid with exact pixel values (Margin: 72, Gutter: 16), designed at 1920x1080.

**Key finding:** The vast majority of brand guidelines (~76%) do not distinguish between web and print typography. This is a significant gap, particularly for digital-first brands. Where distinctions exist, they tend to focus on fallback font substitution for web/email rather than on responsive sizing, viewport-aware scaling, or CSS-specific properties.

## 9. Best Examples -- Top 5 Typography Sections

### 1. Marina Dorcol (D008) -- Score: 5/5 for typography

**Why it excels:** The most complete typographic system in the Diorama portfolio. Defines 10 hierarchy levels from Display 1 (72/80) through Overline (13/16), with explicit size/leading values for each. Clean separation between Cera Stencil Pro (display) and Cera Pro (body). The stencil typeface creates an instant visual signature that carries the entire identity without additional graphic devices. Navigation symbols integrated as part of the typographic system.

### 2. CORWIN (D016) -- Score: 4.5/5 for typography

**Why it excels:** Percentage-based hierarchy (300% down to 80%) that scales across any medium. Spacing system uses multipliers (1x, 2x, 3x, 4x). Two-tier font system (Circular + Poppins fallback) with identical hierarchy specs for both. The approach is resolution-agnostic and design-system-ready. Clear rationale for each typeface choice.

### 3. Noveba (D033) -- Score: 5/5 for typography

**Why it excels:** Sizes designed in multiples of 8 for mathematical vertical rhythm (136pt, 80pt, 56pt, 32pt, 24pt, 16pt). 12-column grid specification with exact margin/gutter values. Three-tier system (Bagoss Condensed + Saans + Arial fallback) with clear role assignments. The multiples-of-8 approach is the most design-systems-minded specification in the entire corpus.

### 4. Nordika (D018) -- Score: 4.5/5 for typography

**Why it excels:** Precise rule that headline sizes should be multiples of 36 (144, 108, 72, 36pt). Explicit letter-spacing (-3% for headlines above 36pt, 0% below). Line-height rule: 100% for headlines, auto for body. Clean two-face separation: LL Supreme (logo only, 12% tracking) and Neue Haas Unica (everything else). The mathematical precision is exceptional.

### 5. Gerulata (D029) -- Score: 4.5/5 for typography

**Why it excels:** 11 distinct text styles with exact size/leading specifications (H1: 135/120 through Body Tiny: 14/21). PP Telegraf as secondary with full weight documentation. The most granular hierarchy in the corpus, suitable for direct implementation in a design system or CSS framework.

### Honorable Mentions

- **Ogilvy** (E085): THE standout custom typography in the new batch. Custom Ogilvy Sans + Ogilvy Serif designed by COLLINS/MCKL. Features 3 numeral sets, explicit wordspacing specifications, a 66-character ideal line length, a "gi" ligature prohibition, and Johnston heritage lineage. The most typographically detailed document added since the original corpus.
- **SHARK** (D002): Pioneering percentage-based scale (900% to 80%) with line-heights and the web/print/email fallback chain.
- **REMPO** (D009): Clean 9-level hierarchy (Display 1 through Overline) with size/leading ratios expressed as adaptable guidelines, not fixed values.
- **Kolinska Distrikt** (D021): Pixel-based scale designed for 1920x1080 with negative tracking for headlines (-4% to 0%) and explicit layout spacing rules.
- **DocuSign** (E074): DS Indigo custom typeface with Light weight for headlines (inverting convention) and 6 weights with systematic role assignments.
- **IOC** (E070): Three bespoke Olympic typefaces with non-Latin alternates, variable font capabilities, and textile/thread specifications.
- **Havas** (E086): x/x2/x4 proportional sizing rule with a strict max 3 sizes per application -- an unusually tight constraint that forces hierarchy discipline.

## 10. Toolkit Implications -- Typography System Recommendations

Based on the patterns, gaps, and best practices observed across 180 documents, the following recommendations apply to the Service Portal's brand guideline toolkit:

### A. Require a Minimum Hierarchy Specification

Every brand guideline should define at minimum 5 hierarchy levels:
1. **Display / Headline** (largest)
2. **Subheadline**
3. **Body** (base unit = 100%)
4. **Small / Caption**
5. **Overline / Label**

The toolkit should provide a template that enforces this minimum while allowing expansion to 7-11 levels for more complex systems.

### B. Support Both Absolute and Relative Sizing

The corpus is split between absolute (pt/px) and relative (%) approaches. The toolkit should:
- Default to **percentage-based sizing** for flexibility (following the Diorama convention of base = 100%)
- Allow override to absolute values when projects require pixel-perfect specification
- Always require **line-height** alongside size (the two are inseparable)
- Encourage **tracking** specification for at least display levels

### C. Mandate a Three-Tier Font System

The most robust typography sections define three tiers:
1. **Primary** -- brand typeface(s) for ideal usage
2. **Secondary / Web** -- freely available alternative (Google Fonts) when licensing prevents primary use
3. **System / Fallback** -- Arial, Helvetica, Georgia for email, office docs, and uncontrolled environments

The toolkit should require at least Tier 1 and Tier 3, with Tier 2 recommended.

### D. Standardize Level Naming

Based on corpus frequency, adopt the following standard level names:
- `display` (optional, for the largest presentation-scale type)
- `headline` (H1-H3 if needed)
- `subheadline`
- `body` (base unit)
- `small`
- `caption`
- `overline` (uppercase label/tag style)
- `footnote` (optional, for the smallest text)

Avoid the Diorama-specific "Sequencer" term in the toolkit standard, as it has no recognition outside the studio.

### E. Provide Foundry Guidance

The toolkit should include a curated shortlist of recommended foundries based on corpus analysis:
- **Premium commercial:** Displaay, Pangram Pangram, Lineto, Typemates, Commercial Type, Sharp Type, Klim
- **Free/Google Fonts alternatives:** Work Sans, Inter, Poppins, Manrope, Space Grotesk (pair well with commercial display faces)
- **System fallbacks:** Arial (universal sans), Georgia (universal serif), Helvetica (macOS sans)

### F. Close the Web/Print Gap

Only 15% of documents distinguish between digital and print typography. The toolkit should include mandatory fields for:
- Web font format and loading strategy (WOFF2, variable fonts)
- CSS font stack specification
- Responsive sizing approach (clamp(), viewport units, or breakpoint-based)
- Email fallback specification
- Minimum and maximum font sizes for accessibility (16px body minimum)

### G. Enforce Spacing Specifications

Require the following alongside every type hierarchy:
- **Line-height** for every level (non-negotiable)
- **Tracking/letter-spacing** for at least display and overline levels
- **Paragraph spacing** (distance between text blocks)
- **Maximum line length** (characters per line; the SHARK guideline of 70 chars/line is an excellent benchmark)

### H. Document Weight Rationale

The toolkit should require documentation of which weights are used and why:
- Minimum: Regular + Bold (2 weights)
- Recommended: Light/Regular/Medium/Bold (4 weights)
- Each weight should have a defined role (e.g., "Medium: subheadings and UI labels")

### I. Type-as-Identity Consideration

Several of the strongest brand systems in the corpus use typography itself as the primary brand differentiator, rather than relying on logos or graphic devices:
- KBT's Block-Raw-Sculpt variable font metaphor
- Marina Dorcol's stencil cuts as visual rhythm
- Rajska 5's Macan Stencil as industrial elegance
- TECHBOX's italic axis as kinetic energy
- Queens' custom Q as generative graphic system

The toolkit should include a "typographic concept" field that encourages brands to articulate how their typeface choice connects to their brand story -- not just what font they use, but why.

### J. Accessibility Baseline

Fewer than 5% of documents in the corpus address typographic accessibility. The toolkit should enforce:
- Minimum body text size: 16px (digital) / 11pt (print)
- Minimum contrast ratio: 4.5:1 for body text, 3:1 for large text (WCAG AA)
- Line-height minimum: 1.5x for body text
- Maximum line length: 66-80 characters (Ogilvy specifies 66 as ideal; SHARK recommends 70)
- Prohibition of justified text in digital contexts without hyphenation
