# Independent Study 2: Logo Use and Guidelines

**Corpus:** 179 brand guideline documents (36 Diorama, 143 external)
**Date:** April 2026

---

## 1. Logo Variation Taxonomy

Across the corpus, logo systems break down into a consistent set of variation types. Not every brand uses every type, but the taxonomy is remarkably stable.

### Variation types observed

| Variation type | Description | Frequency (approx.) |
|---|---|---|
| **Full lockup** | Symbol/icon + wordmark together | ~137 docs (~77%) |
| **Wordmark only** | Text-only version of the brand name | ~122 docs (~68%) |
| **Symbol / icon only** | Standalone mark without text | ~90 docs (~50%) |
| **Monogram / favicon** | Abbreviated letterform(s) for small-scale use | ~59 docs (~33%) |
| **Stacked / vertical** | Alternative orientation of the lockup | ~54 docs (~30%) |
| **Horizontal** | Primary or alternative horizontal arrangement | ~63 docs (~35%) |
| **Tagline lockup** | Logo + tagline as a fixed unit | ~32 docs (~18%) |
| **Sub-brand lockup** | Parent logo + sub-brand name | ~37 docs (~21%) |
| **Co-branding lockup** | Logo paired with partner logo | ~48 docs (~27%) |

### Average number of variations per brand

The typical brand defines **3 to 5 distinct logo variants**, including orientation changes and colour versions. More sophisticated systems (Oculus/Meta with 28+ pages of logo rules, Stella Artois with 7+ mark types, LA Lakers with 6 named logo forms, NMAAHC with tiered lockup hierarchies) can reach **6 to 10+** distinct configurations.

Simpler brands -- particularly Diorama's smaller projects -- often define just **2 variants**: a primary lockup and a colour-inverted version (e.g., LUCRON, GERULATA, TECHBOX).

### Notable patterns

- **Wordmark-only brands** are common in the Diorama portfolio (LUCRON, NOVEBA, Workin, TECHBOX), while external brands almost universally pair a symbol with a wordmark.
- **Monogram/favicon variants** have become standard in post-2018 guidelines -- nearly every modern brand now defines a small-scale abbreviated mark (Burger King "BK", ANYWHALE "A", Queens "Q", KALW "ka").
- **Stella Artois** has the most logo variants in the corpus: Full Color Cartouche, Red Cartouche, Outlined Cartouche, Horizontal Wordmark, Circular Wordmark, Outlined Stage, Red Stage, and Heritage Marks.

## 2. Clear Space Systems

**106 of 179 documents (59%)** define explicit clear space rules. Among documents that actually cover logo guidelines (excluding ~15 that omit the section entirely or are TOV-only), the coverage rate rises to approximately **65%**.

### How clear space is defined

| Method | Count | Examples |
|---|---|---|
| **Letter-based** (height or width of a specific letter in the wordmark) | ~58 | Height of "H" (SHARK), width of "o" (LUCRON), width of "s" (Sleek), height of "a" (RAC, Avast), cap height of "U" (Uber), width of "M" (British Museum), height of "N" (New Museum), width of "O" (Tramways Coffee, KOYOK) |
| **Element-based** (derived from a specific part of the logo/symbol) | ~27 | Trapezoid width (DEUS), diamond height (Umbro), hexagon width (Bumble), numeral "5" stroke (Rajska), Nexus icon width (Docusign), inner dot diameter (Sleek symbol), half "O" spacing (KOYOK construction) |
| **Percentage / fraction of logo dimension** | ~12 | 50% of symbol height (Howden, Hometree, F1), 1/3 of symbol width (Habitat), 1/4 of logo height (Crafts Council, ICFF), 1/10 of logo length (Targetti) |
| **Fixed / proportional grid unit** (named "X" or "A" unit) | ~8 | "X" unit (Cisco, Bolt, Widelab), "A" unit (NEA), "B" unit (Kia) |

### Most common approach

**Letter-based clear space is the dominant convention**, used by roughly half of all documents that define clear space. The most frequently chosen letters are lowercase "a", "o", or "e" (for their circular, easily measurable forms) and uppercase "H", "U", or "I" (for their vertical strokes). This approach is intuitive because it is self-scaling -- the clear space automatically adjusts as the logo scales.

Diorama consistently uses the letter-based method across its portfolio (FONA uses "O", LUCRON uses "o", SHARK uses "H", Rajska uses "5", Sleek uses "s", CORWIN uses "I", Byteminds uses the square in the symbol).

## 3. Minimum Size

**80 of 179 documents (45%)** specify minimum logo sizes. Among documents with substantive logo sections, the rate is approximately **55%**.

### Units used

| Unit | Context | Count |
|---|---|---|
| **mm** | Print | ~50 |
| **px** | Digital/screen | ~45 |
| **inches** | Print (primarily US brands) | ~20 |
| **pt** | Mixed | ~5 |

Many documents specify **dual minimums** -- one for print (mm or inches) and one for digital (px).

### Common minimums

| Application | Typical range | Most common value |
|---|---|---|
| **Full logo (print)** | 9 mm -- 30 mm | **20 mm** (Diorama standard: CORWIN, In.Kanal, NOVEBA, PROSIGHT all at 20mm) |
| **Full logo (digital)** | 50 px -- 150 px | **120 px** (Diorama standard) |
| **Symbol only (print)** | 3 mm -- 15 mm | **10 mm** |
| **Symbol only (digital)** | 15 px -- 50 px | **20--30 px** |
| **Favicon / icon** | 16 px -- 32 px | **16 px** |

### Notable specifics

- **A Punt** specifies the smallest minimum in the corpus: 5 mm print, 20 px digital.
- **Kia** is similarly small: 5 mm print, 15 px digital.
- **Network Rail** specifies 4x2.5 mm for print and 32x20 px for digital -- among the smallest minimums, reflecting the lozenge form's simplicity at small scales.
- **NMAAHC** specifies 1.5" (38 mm) wide for the horizontal logo -- one of the largest minimums.
- **Crafts Council** prescribes specific logo sizes per print format (A3: 48mm, A4: 36mm, A5: 24mm, business card: 20mm) -- a rare format-by-format approach.
- **Diorama has standardised** on 20 mm / 120 px as its default minimum across multiple projects.

## 4. Construction Grids

**~33 of 179 documents (18%)** include or reference geometric construction documentation for the logo.

### Frequency by category

- **External brands:** ~22 documents (17% of external corpus). More common among heritage brands, large corporations, and design-forward identities.
- **Diorama brands:** ~8 documents (22% of Diorama corpus). Diorama uses construction grids more frequently than the external average, suggesting it is a signature element of their methodology.

### Notable examples

| Brand | Construction detail |
|---|---|
| **Deutsche Bank** | Anton Stankowski's precise geometric construction of the "slash in a square" -- ratio relationships (10:12.3, 30:31), diagonal stroke angle (~53 degrees), grid-based reproduction system |
| **Dreher** | Extraordinarily detailed construction drawings using compass arcs, grid systems, and mathematical relationships for the rounded-square shield shape |
| **Olympic Rings (IOC)** | Strict geometric grid: one ring = 12x the thickness of a ring; space between rings = one ring thickness |
| **NASA** | Grid drawing provided specifically for large-scale logotype reproduction where photomechanical methods are impractical |
| **Bell System** | Saul Bass's bell-in-circle with grid pattern for large-scale reproduction |
| **US Army Corps** | Grid drawing provided for oversized applications (Chapter 9) |
| **Oktawave** | Logo constructed using golden ratio proportions |
| **NORDIKA** (Diorama) | Symbol built on an 11x21 square grid; one grid module = line thickness |
| **Marina Dorcol** (Diorama) | Detailed construction grid showing symbol built on a square grid with diagonal construction lines |
| **NEA** | Detailed construction grid with proportional measurements (12A, 6A, 5A, 2A relationships) |
| **Peloton** | Construction grid with X/Y proportional system |
| **Ogilvy** | Specific width-to-height ratio (330:129) with a verification method |
| **Network Rail** | Golden ratio 8:5 redesign of the classic British Rail lozenge; includes 3D fabrication specifications for physical signage |
| **KOYOK** | Unified K letterform with construction spacing derived from half the width of the "O" character |

### Observations

Construction grids appear to serve three distinct purposes:
1. **Reproduction accuracy** (vintage/heritage brands: Bell System, NASA, US Army Corps) -- ensuring the mark can be reproduced at scale before digital asset distribution existed.
2. **Design rationale** (Deutsche Bank, Dreher, Olympic Rings) -- demonstrating the intellectual rigour behind the mark.
3. **Modular extension** (NORDIKA, NEA, KALW) -- the grid becomes the basis for broader design system patterns and layouts.

Modern brands increasingly use construction grids for purpose #3, while vintage documents focused almost exclusively on purpose #1.

## 5. Misuse / Incorrect Usage

**~95 of 179 documents (53%)** include explicit misuse examples or prohibition lists.

### Average number of don'ts

Among documents that include misuse guidance, the average is **7 to 9 specific prohibitions**. The range spans from 3 (minimal lists) to 24 (comprehensive lists like Network Rail, Kia, Zoom, LA Lakers, Bumble).

### Most common misuse categories

Ranked by frequency across all documents:

| Rank | Category | Approx. frequency |
|---|---|---|
| 1 | **No stretching / distortion** | ~80 docs |
| 2 | **No rotation** | ~65 docs |
| 3 | **No unapproved colours** | ~60 docs |
| 4 | **No low-contrast backgrounds** | ~55 docs |
| 5 | **No placement on busy photography** | ~45 docs |
| 6 | **No drop shadows / effects / 3D** | ~40 docs |
| 7 | **No enclosure in shapes** (circles, boxes) | ~30 docs |
| 8 | **No outlined / stroked versions** | ~25 docs |
| 9 | **No recreating / resetting type** | ~25 docs |
| 10 | **No gradient fills** | ~20 docs |
| 11 | **No opacity / transparency changes** | ~15 docs |
| 12 | **No animation / personification** | ~10 docs |

### Brands with most comprehensive misuse sections

- **Network Rail:** 24 documented misuse examples -- tied with Kia for the most in the corpus. Covers every conceivable distortion, colour misapplication, and placement error for the lozenge mark.
- **Kia:** 24 documented rules, including prohibitions on complex backgrounds, watermark patterns, and vertical usage.
- **Zoom:** 12 rules, notably including "no old versions" and "no lockup with copy or other logos."
- **LA Lakers:** 12 rules for the primary logo alone, with additional rules for secondary marks.
- **Bumble:** 12 rules including no stacking and no effects.
- **Twitter (v1):** 10 illustrated misuse examples with a focus on no anthropomorphising, no accessories.
- **McDelivery:** 10 violations documented.
- **LUCRON** (Diorama): 9 examples -- comprehensive for a relatively simple wordmark.
- **Generali Balans** (Diorama): 9 examples.
- **KALW:** 9 examples.
- **Havas:** 7 don'ts for the lowercase "h" mark, governing tint misuse, rotation, and colour application.
- **Slack:** Misuse rules segmented by logo type (core, API, partnership) -- a layered approach.

### Observations

- Diorama's documents include misuse sections more consistently than the external corpus average, typically showing 6 to 9 illustrated don'ts.
- The most universal prohibition is **no stretching/distortion** -- it appears in virtually every document that has any misuse section at all.
- Modern tech brands (Zoom, Slack, Dropbox, Discord) tend to include **"no old versions"** as a misuse rule -- reflecting the reality of frequent rebrands.
- Apple's channel guidelines take a uniquely restrictive approach: "Never use Apple logo standalone" -- the opposite of most brands' symbol-only provisions.

## 6. Colour Variants

### Typical colour context count

Most brands define **3 to 5 colour contexts** for their logo:

| Context | Description | Frequency |
|---|---|---|
| **Full colour on light** | Primary version | ~140 docs |
| **Full colour on dark** | Inverted/negative version | ~120 docs |
| **Monochrome black** | For single-colour printing | ~90 docs |
| **Monochrome white** | Reversed on dark backgrounds | ~100 docs |
| **On brand colour backgrounds** | Logo on each palette colour | ~60 docs |
| **On photography** | Rules for placement over images | ~50 docs |
| **Grayscale** | For budget or legibility constraints | ~25 docs |

### Average number of defined colourways

- **Simple brands:** 2 (black + white). Examples: LUCRON, GERULATA.
- **Typical brands:** 4 (full colour light, full colour dark, mono black, mono white). This is the most common pattern.
- **Complex brands:** 6 to 10+ explicit colourways. Examples: Aludium (6 presentation modes), DSTRCT Berlin (4 background variants x 2 colour treatments), NMAAHC (3 colours x multiple lockups).

### Notable approaches

- **Howden** defines the most expressive colour system: Solid colour, Lens effect (photography visible through logo), Lens on white, Gradient fill, Atmospheric, and Colour on photography -- six distinct "expressions."
- **Channel 4** allows the logo to adopt the colour of whatever image it overlays -- a continuously variable approach.
- **Channel Five** permits the logo in any of 25 palette colours plus black or white.
- **Havas** provides the lowercase "h" in 8 colour options with a 100/60/40 tint system -- creating an expressive yet controlled colour identity for the mark.
- **Ferrari** defines production-specific variants: Pantone 426, 3D (headed paper only), B&W line art, Silver on red (hot silver or Pantone 877), and Embossed.
- **Diorama's standard approach** is to define 2 to 4 colour variants, typically: primary colour on light, white on dark, and sometimes black-only for monochrome reproduction.

## 7. Co-branding

**~59 of 179 documents (33%)** address co-branding or partner logo placement.

### Approaches

| Approach | Description | Examples |
|---|---|---|
| **Separator line** | Vertical divider between logos | Uber, Docusign, CORWIN, NOVEBA, Aix-Marseille, NMAAHC |
| **Proportional spacing** | Clear space unit multiplied for inter-logo gap | Kia (MAX 2K horizontal), Bumble (hive cutout width), Oyster (33% of logo width) |
| **Baseline / height matching** | Partner logos aligned and sized relative to primary | ASICS, Opera, Slack, Twitch, NorthAlley |
| **Hierarchical sizing** | Primary brand larger, partner at defined fraction | CORWIN (1/2x to 1/6x), Tokyo Olympics (emblem smaller than NOC) |
| **Dedicated co-brand lockup** | Pre-designed combined mark | Motorola+Lenovo, DSTRCT+HB Reavis, Workin by Corwin, Kolinska Distrikt+Corwin |
| **Approval required** | Partner lockups only with brand team sign-off | American Express, Peloton, Acura, Umbro |

### Depth of co-branding guidance

- **Minimal** (~20 docs): A single line noting that partner logos should be spaced or sized appropriately.
- **Moderate** (~25 docs): Specific spacing units, separator rules, and 2 to 3 illustrated examples.
- **Comprehensive** (~11 docs): Detailed systems with multiple configuration options, hierarchical rules, and explicit approval processes. Best examples: **CORWIN** (Diorama), **Kia**, **Slack**, **Aix-Marseille**, **NMAAHC**, **Oculus**.

### Diorama's co-branding practice

CORWIN stands out with the most detailed co-branding system in the Diorama portfolio: sub-brand lockups ("Offices by Corwin"), collaboration lockups ("something x Corwin"), co-branding with divider line, and multi-logo composition with hierarchical sizing. NOVEBA addresses co-branding with IBS Invest. These serve as internal templates for how Diorama approaches parent/partner relationships.

## 8. Responsive Logos

**~46 of 179 documents (26%)** address size-dependent logo simplification or define distinct small-scale variants.

### Types of responsive behaviour

| Type | Description | Examples |
|---|---|---|
| **Dedicated small-use version** | Separate artwork optimised for small sizes | Bell System (Version B for < 3/4"), Generali Balans (simplified gospel below 140mm), MICA (three scale versions per lockup), Burger King (small-use logo < 0.75"), Ferrari (Small Size vs Large Size), HSBC (custom small usage versions for hexagon < 8mm) |
| **Weight swap** | Heavier weight at small sizes for legibility | SHARK (Regular to Medium at small sizes), British Museum (optically adjusted small version at 16mm) |
| **Symbol-only fallback** | Full lockup reduces to symbol at small sizes | Nearly universal -- ~50+ docs define this implicitly or explicitly |
| **Favicon / monogram variant** | Specific abbreviated mark for digital icons | Burger King "BK", ANYWHALE "A", Queens "Q", KALW "ka", Rempo "R", CORWIN icon |
| **Three-tier scaling** | Large / medium / small versions with distinct artwork | MICA (Large > 1/2", Regular 1/16"--1/2", Small 1/16"--3/64"), F1 (Standard, Display, Micro), Supercell (4 size tiers by ratio) |

### Is this an emerging trend?

Yes, but it is not new. The concept has existed since at least the 1970s (Bell System's Version A/B system, designed by Saul Bass) and 1980s (Apple Vintage guidelines with size-dependent colour simplification). What has changed is:

1. **Formalization**: Modern brands (post-2015) are more likely to name and systematize their responsive variants rather than relying on designer judgement.
2. **Digital-first thinking**: Favicon and app-icon variants are now standard requirements, not afterthoughts.
3. **Three-tier systems** are becoming more common: F1's Standard/Display/Micro and MICA's Large/Regular/Small represent a maturing approach.
4. **Optical compensation**: Brands like SHARK (weight swap) and British Museum (optically adjusted small version) show increasing attention to perceptual fidelity across scales.

The most sophisticated responsive system in the corpus is **MICA**: custom-drawn artwork at three scales per lockup variant, with distinct forms at each scale to maximise legibility -- never just a scaled-down version of the large artwork.

## 9. Best Examples -- Top 5 Logo Guideline Sections

### 1. Kia (E069)

**Why:** The most comprehensively structured logo section in the corpus. Covers philosophy (Symmetry, Rhythm, Rising), construction anatomy (beveled ends, modulated strokes, inter-character connections), clear space with named unit, minimum sizes in both print and digital, grayscale background decision guide, systematic expansion rules for service/location lockups, detailed co-branding with proportional specifications, dual-brand composition (Hyundai + Kia), and 12 documented misuse rules. It is both principled and granular.

### 2. CORWIN (D016, Diorama)

**Why:** The best Diorama logo section and among the best in the full corpus. Defines horizontal and vertical orientations with distinct construction rules for each. Clear space tied to a specific letter ("I"). Minimum sizes for both orientations. Favicon provision. Four levels of co-branding (sub-brand, collaboration, co-branding with divider, multi-logo hierarchy). Every rule is expressed as a formula (e.g., "spacing = 2x the gap between symbol and text"). Demonstrates how a mid-size brand can achieve enterprise-level rigour.

### 3. F1 / Formula 1 (E060)

**Why:** Exemplary three-tier responsive system (Standard, Display, Micro) with distinct artwork per tier. Clear space at 50% of logo height -- simple and memorable. Orientation rules that specifically address rotation direction (anticlockwise only; clockwise prohibited). Lock-up hierarchy (descriptor variant for third-party contexts, championship variant for sporting use). Misuse rules documented per variant. The system balances creative flexibility with absolute control.

### 4. Bumble (E061)

**Why:** Achieves completeness in a compact format. Clear space from the hexagonal hive. Minimum size in three units (px, mm, inches). Brand partnership lockup with a precise spacing system. App icon rules. And 12 misuse rules. The standout feature is the internal consistency: every measurement derives from the hive geometry, making the entire system feel inevitable rather than arbitrary.

### 5. NMAAHC / National Museum of African American History and Culture (E159)

**Why:** Demonstrates how a museum brand with strong symbolic meaning (Yoruban crown / building architecture) can maintain tight controls while serving diverse contexts. Three-tier icon, vertical and horizontal variants, three approved colours, lockup combinations with Smithsonian parent brand and tagline (with an explicit "never all three combined" rule). Icon-only use requires OPA approval and is restricted to social media / promotional items. Department lockup system. Partner co-branding hierarchy. Misuse guidance. One of the most complete institutional logo systems.

### Honourable mentions

- **Oculus (E051):** 28+ pages of logo guidance, covering endorsement lockups, optical adjustments, and content partnerships -- the most extensive logo section by page count.
- **Slack (E071):** Excellent brand architecture approach with four tiers (external, internal programs, adjacent brands, master brand offerings) each with distinct logo treatment.
- **MICA (E002):** Custom-drawn artwork at three scales -- the gold standard for responsive logo design.
- **Apple Vintage (E144):** A masterclass in colour specification and clear space definition from 1987, still relevant today.
- **Network Rail (E084):** 24 misuse examples (tied for most in corpus), golden ratio 8:5 construction, lozenge variant system, and 3D fabrication specs for physical signage.
- **KOYOK (E079):** Unified K letterform with mathematically derived construction spacing -- clean, systematic, and illustrative of how a simple mark can be rigorously specified.
- **The Shed (E149):** Typography-as-logo approach with horizontal rules framing -- demonstrates how conceptual art thinking can produce a distinctive identity without a conventional symbol.

## 10. Toolkit Implications

Based on the patterns observed across 179 documents, the AI toolkit should address the following for logo sections:

### Must-have content blocks

1. **Logo anatomy** -- Name and describe each component of the logo (symbol, wordmark, tagline, descriptor). Show the relationship between parts.
2. **Variant inventory** -- Define all approved configurations: horizontal lockup, stacked lockup, symbol only, monogram/favicon, tagline lockup. Provide distinct artwork for each.
3. **Clear space** -- Define using a letter-based or element-based unit (the corpus strongly favours this over fixed dimensions). Show the rule visually with the measurement unit labelled.
4. **Minimum size** -- Specify in dual units: mm for print, px for digital. Diorama's standard (20 mm / 120 px) is a sensible default.
5. **Colour variants** -- At minimum: full colour on light, full colour on dark, monochrome black, monochrome white. Show each on its correct background.
6. **Misuse examples** -- Include 6 to 9 illustrated don'ts. The universal set: no stretching, no rotation, no unapproved colours, no low-contrast backgrounds, no busy photography, no drop shadows/effects, no enclosure in shapes.

### Should-have content blocks

7. **Co-branding rules** -- Separator system (line or space), proportional sizing, alignment method. Provide at least one illustrated example.
8. **Construction rationale** -- Brief explanation of the design logic (grid, proportions, typographic derivation). Does not need to be a full construction grid for every project, but should exist for complex symbol marks.
9. **Favicon / app icon** -- Dedicated small-scale variant with its own colour and sizing rules. This is now a baseline expectation.
10. **Background decision matrix** -- When to use which colour variant based on background lightness (the Kia grayscale guide is the best model).

### Nice-to-have / advanced content blocks

11. **Responsive scaling system** -- For brands with complex symbols, define 2 to 3 scale tiers with distinct artwork (following MICA and F1 models).
12. **Placement rules** -- Fixed-position systems (Sony: top-right at 2h from edges; WeWork: bottom-right as sign-off; PROSIGHT: bottom-left always). Not universal but adds consistency.
13. **Trademark symbol rules** -- When and where to display (R) or TM (Cisco's size-dependent TM rules are the best reference).

### Generation logic for the AI

- **Clear space rule** should be auto-derived from logo anatomy: if the logo has identifiable letterforms, use a letter-based unit; if it is a pure symbol, use a percentage of the symbol's height.
- **Minimum size** should default to 20 mm / 120 px unless the logo has fine detail requiring a larger minimum.
- **Misuse set** should always include the top 6 prohibitions (stretching, rotation, colour, contrast, photography, effects). Additional rules should be context-specific (e.g., "no old versions" for rebrands, "no anthropomorphising" for character-based marks).
- **Colour variants** should be auto-generated from the brand palette: if the palette has a primary dark + primary light, produce positive and negative lockups on each.
- **Co-branding template** should be generated whenever the brand has a parent company, partner ecosystem, or sub-brand architecture.

### Cross-reference with other studies

- Logo colour variants should reference the **colour system study** (Study 01) for palette definitions and contrast rules.
- Logo typography should reference the **typography study** (Study 03) for font pairing within lockups.
- Co-branding rules should reference the **brand architecture study** for hierarchical relationships.
