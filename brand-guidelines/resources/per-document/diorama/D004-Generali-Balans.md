## Brand Strategy

The document positions Generali Balans as a **sub-brand** ("subbrand") of the parent Generali insurance brand. The name is always written as "Generali Balans" in running text. The manual focuses exclusively on the sub-brand's visual identity layer -- specifically how the hand-written "Balans" wordmark pairs with the existing Generali lion logo. No mission statement, brand values, positioning, target audience, or brand architecture diagram is provided. Strategic context is minimal; the manual assumes familiarity with the parent Generali brand system.

## Logo Guidelines

### Primary logotype (p. 3)
The Generali Balans logotype is composed of two elements:
1. **GENERALI Logo** -- the existing Generali winged-lion icon with "GENERALI" wordmark beneath it.
2. **Hand-written wordmark** -- a custom, script-style "Balans" lettering with an underline stroke, placed to the right of the Generali logo.

The "Balans" wordmark is rendered in a fluid, calligraphic hand-lettering style (not a standard typeface). An underline flourish gives it visual emphasis within the pair.

### Versions (p. 4)
Two layout orientations are defined:
- **Horizontal version** -- Generali logo left, "Balans" script right, side by side.
- **Vertical version** -- Generali logo stacked above the "Balans" script.

### Clear space / safety zone (p. 5)
The exclusion zone for both versions is defined by a **square whose edge length equals the empty space between the two logo elements** (the Generali icon and the Balans wordmark). This square's area is projected outward on all sides.

### Size-dependent gospel versions (p. 6)
Two variants of the lion's "gospel" (the scroll/tablet the lion holds) exist, inherited from the parent Generali manual:
- **140+ mm width** -- use the gospel version with text (detailed rendering).
- **40--140 mm width** -- use the gospel version with lines (simplified rendering).
- **Below 40 mm** -- usage is not recommended.

### Color usage on backgrounds (p. 7)
- **Light backgrounds** -- logotype in Red 1.0 (primary red).
- **Dark backgrounds** -- logotype in white.

### Grayscale / black-and-white usage (p. 9)
For monochrome environments, the logotype can appear in black on light backgrounds. A full gradient chart (10%--100% black backgrounds) shows the logo transitioning from black to white as background darkness increases.

### Prohibited usage (p. 11)
Nine explicit misuse examples are shown:
1. Low-contrast background with logotype.
2. Rotation of the logotype.
3. Non-proportional scaling (stretching/squashing).
4. Using the "Balans" wordmark part alone, without Generali.
5. Incorrect element order (Balans before Generali).
6. Incorrect element order (reversed stacking).
7. Incorrect color combinations (e.g., yellow/pink variants).
8. Placement inside arbitrary geometric shapes (e.g., circle).
9. Placement on a photograph with insufficient contrast.

## Supporting Graphics

### Colored stripes (pp. 8, 14, 17)
The primary graphic device is a system of **horizontal color stripes** using tints (10%--90%) of the defined palette colors. These appear as:
- Bands of graduated tint across merchandise and key visuals.
- Diagonal stripe wraps on 3D merchandise (e.g., water bottle).
- Horizontal bar overlays on advertising photography.

### Illustrated stripes (p. 18)
A variant approach uses **colored illustrative stripes that complement photography** -- organic, flowing color bars overlaid on or adjacent to photos, creating a dynamic, energetic feel.

### Generali parent elements
The manual references that additional graphic elements (beyond stripes) are covered in the parent **Generali Look&Feel 2017** document. This sub-brand manual does not define its own icon set, patterns, or illustration style beyond the stripe system.

## Photography

### Style (pp. 17--18)
Two key visual examples show the intended photography direction:
- **Active lifestyle imagery** -- a person running outdoors in athletic wear (hoodie, urban/bridge setting), shot from low angle with motion energy.
- **Sport/wellness portrait** -- a young man in a gym holding a medicine ball, direct eye contact, warm natural lighting, casual athletic wear (dark red t-shirt).

### Integration with brand
Photography is combined with the stripe graphic system:
- Horizontal red bars with the logotype and social media icons overlay the bottom of images.
- Illustrated color stripes frame or interact with the subject (e.g., concentric red rings radiating from the subject's body).
- Large typographic quotes in white appear over the image ("LOREM IPSUM DOLOR" placeholder shown).

### Direction
The photography conveys health, balance, physical activity, and youthful energy -- consistent with the "Balans" (balance/wellness) positioning within insurance.

## Outliers / Notable

1. **Sub-brand only manual** -- This is not a standalone brand system. It is a thin extension layer that defines only the "Balans" wordmark pairing and color usage. It explicitly defers to the parent **Generali Look&Feel 2017** for broader identity rules, which limits its standalone usefulness.

2. **Hand-lettered wordmark** -- The "Balans" script is a custom hand-lettering, not a typeface. The manual does not provide construction details, vector source references, or alternative rendering guidance. This is the brand's single most distinctive asset.

3. **Page numbering gap** -- The section numbering jumps from 1.3 (clear space) directly to 1.7 (size versions), suggesting pages 1.4/1.5/1.6 were either removed, renumbered, or misordered in the InDesign source. The color definition page is labeled 1.4 but appears as page 8, while the color-on-background page (1.5) precedes it at page 7. Some internal inconsistency in section ordering.

4. **Sport/wellness positioning** -- The merchandise choices (water bottle, wristbands, basketball) and photography (running, gym) strongly position this as a health/wellness insurance product, not a general insurance line.

5. **Minimal digital guidance** -- No responsive logo behavior, screen-specific color values (sRGB gamut), favicon specifications, or UI component guidance. The manual is print-production oriented (PDF/X-4, CMYK-first color definitions, Pantone references).

6. **Single typeface dependency** -- Helvetica Neue is the only specified typeface. No web-safe fallback or system font alternative is mentioned.
