## Brand Strategy

The brand identity is directly derived from the architecture of the building itself. The concept section (pp. 3-5) presents inspiration drawn from building materials -- brick, stone masonry, terracotta facade cladding -- and Nordic/Scandinavian architectural references. The name "Nordika" reinforces a Nordic association while the building is located in Ljubljana, Slovenia.

Key messaging lines observed across applications:
- "The perfect place to call home" (primary headline)
- "Vibrant neighborhood" (secondary tagline)
- "Experience the best of city living" (tertiary headline)
- "Premium apartments available" (sales-focused)
- "Last apartments available" (urgency CTA)

The brand positions the project as a premium, architecturally distinctive urban residence combining Scandinavian design sensibility with the warmth and materiality of terracotta and brick.

No formal brand values, mission statement, or brand story text is included -- the concept is communicated visually rather than verbally.

## Logo Guidelines

The Nordika logo consists of two elements:
1. A geometric symbol inspired by the architecture of the building -- an abstracted window/facade form composed of rectangular shapes within a vertical rectangle.
2. The wordmark "NORDIKA" in uppercase, spaced lettering (LL Supreme, 12% letter spacing).

Configurations:
- Vertical (stacked): Symbol above wordmark. Primary arrangement.
- Horizontal: Symbol to the left of wordmark.

Construction: The symbol is built on an 11x21 square grid. One grid module equals the thickness of the symbol's lines (p. 8).

Color variations (p. 9):
- Terracotta on white (preferred)
- White on terracotta
- White on black
- Black on white (fallback)

Safe zone:
- Vertical version: Defined by a square based on the symbol size (p. 10).
- Horizontal version: Defined by the size of the symbol itself (p. 11).

Minimum size (p. 12):
- Vertical: 10mm width
- Horizontal: 15mm width

Don'ts (p. 13): No rotating, recoloring, using different fonts, altering proportions, or stretching/distorting. Six incorrect examples shown.

Social media profile icons: Symbol only (no wordmark) in a circle -- terracotta circle with white symbol or black circle with white symbol (p. 48).

## Typography

Logo typeface: LL Supreme
- Used exclusively for the wordmark
- Letter spacing: 12%

Primary brand typeface: Neue Haas Unica
- Weights used: Medium and Regular
- Strongly recommended for all text including headlines

Type scale (p. 20):
- Heading 1: 144pt / letter spacing -3% / line height 100%
- Heading 2: 108pt / letter spacing -3% / line height 100%
- Heading 3: 72pt / letter spacing -3% / line height 100%
- Heading 4: 36pt / letter spacing -3% / line height 100%
- Heading 5: 20pt / letter spacing 0% / line height auto
- Paragraph: 16pt / letter spacing 0% / line height auto
- Small Text: 12pt / letter spacing 0% / line height auto

Rule: Headline sizes should be multiples of 36. For headlines over 36pt, letter spacing is set to -3% and line height to 100%.

## Supporting Graphics

Pictograms (pp. 21-23):
- Constructed on a 24x24 square grid in a narrow style
- Stroke corners are sharp, caps are flat
- Line-weight consistent across the set
- Example set includes: directional arrow, male figure, female figure, shower, umbrella/terrace, bicycle, elevator, stairs, coffee cup
- Used in wayfinding signage alongside uppercase labels

Grid lines as decorative element:
- The brand's layout grid lines (thin rules dividing the composition into sections) are used as a visible, decorative graphic device across all touchpoints
- These lines appear on posters, merchandise (tote bags, t-shirts, notebooks), signage, and digital applications
- They reference the building's facade grid and create a distinctive, architectural graphic language

No dedicated tone of voice section exists in the document. However, the messaging observed across applications suggests:

## Outliers / Notable

1. Grid lines as brand asset: The most distinctive feature of this identity is the use of visible layout grid lines as a decorative and branding element. They appear on everything from posters to t-shirts to notebooks, creating a unique architectural graphic language that directly references the building's facade.

2. Project-specific identity: This is a brand identity for a specific building project, not a corporate identity. It is tied to the Nordika residential tower development at Masarykova 36, Ljubljana.

3. Parent company relationship: The developer is Corwin. Dual-branding templates are provided (pp. 53-54) showing how the Nordika and Corwin logos coexist. The document footer reads "Diorama for Corwin" throughout.

4. Slovenian context: Despite English-language marketing copy, the project is in Ljubljana, Slovenia. The website is nordika.si (Slovenian TLD). Contact address shows Dunajska cesta 159, 1000 Ljubljana, Slovensko.

5. Two typeface system: LL Supreme is reserved exclusively for the logo wordmark. Neue Haas Unica handles all other text. Both are premium, licensed typefaces.

6. Symbol derived from architecture: The logo symbol is explicitly described as inspired by the building's architecture, making it a site-specific mark rather than a generic real estate brand.

7. No brand values or mission text: The document is purely visual/tactical -- no brand strategy narrative, positioning statement, or tone of voice guidelines are provided.

8. Accent Green for CTAs only: The green color (#53BBB2 / Pantone 360U) is used exclusively for call-to-action elements -- "MORE INFO" buttons, "APARTMENTS ON SALE" labels, and the occasional tagline highlight. Never as a background or primary color.
