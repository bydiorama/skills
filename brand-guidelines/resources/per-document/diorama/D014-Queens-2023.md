## Brand Strategy

- Document is titled "Visual Guidelines 2023" -- positioned as a visual-language rulebook, not a full brand-strategy deck.
- Introduction (p2) frames the purpose: "outlines the visual language of the Queens brand and how it should be used, including examples of how it can be applied."
- Emphasis on consistency across all media and channels.
- No explicit mission, vision, values, or brand-positioning statements found. Strategy is implicit through visual choices.

## Logo

- **Type:** Wordmark set in Haffer typeface with a customized capital "Q" letter.
- **Typeface variant:** Uses Haffer XH (extra-high x-height) for increased legibility at small sizes.
- **Heritage:** Inherits composition from predecessor logo; new typeface gives "fresh and more elegant look."
- **Symbol:** The standalone "Q" can be used when full wordmark is redundant or space-constrained. Full wordmark is always preferred.
- **Clear space:** Specified (visual examples, no numeric value extracted from text).
- **Color options:** Multiple color lockups shown (p7, p9) -- logo and symbol both have defined color variants.
- **Hierarchy rule (p10):** Full logo = primary; symbol = secondary for compact/scale-restricted contexts.

## Typography

- **Primary (only) font:** Haffer -- designed by Czech type designer Martin Vacha with Daniel Quisek (2021).
- **Weights used:** Regular, Medium, SemiBold (standard); Regular, Medium (XH variant).
- **XH variant:** Haffer XH has significantly higher x-height, used specifically for the logo wordmark.
- **Character set:** Latin Extended-A (Western, Central, Southeastern European + Vietnamese). OpenType features supported.
- **Spiritual lineage:** Univers (1957), Avenir (1987), Neuzeit (1928), Proxima Nova (current corporate typeface it replaces/evolves from).

### Typographic Hierarchy
| Level | Size | Line Height |
|-------|------|-------------|
| Large Headline | 300% | 0.95 |
| Headline | 200% | 0.95 |

- Hierarchy defined in relative percentages (not absolute px/pt), making it flexible across media.
- Tight line-heights for headlines (0.95), standard for body (1.20).

## Graphic Elements

- **Tags and shapes** are the main graphic-support elements enhancing brand recognition.
- Tags are geometric shapes (with inner holes) used as supporting visual elements alongside logo.
- Tags can be: rotated, scaled, multiplied, misplaced, overlapped to create compositions.
- **Four composition scales defined (p23):**
  - **Exploded** -- tag symbols without inner hole, abstract layouts.
  - **Oversized** -- default state with inner hole, large scale.
  - **Standard Size** -- default state with inner hole, normal scale.
  - **Confetti** -- tag symbols without inner hole, small scattered elements.
- Color combinations allowed from full brand palette; must maintain adequate contrast against copy.
- Tags must remain subordinate to logo and key message in any material.

## Outliers / Unique Elements

- **Haffer XH variant** for logo is unusual -- leveraging a specialist optical-size variant specifically for the wordmark.
- **Tag composition system** with 4 named scale modes (Exploded, Oversized, Standard, Confetti) is a distinctive graphic framework.
- **15-color system** (5 families x 3 tints each) is more elaborate than typical retail brand palettes.
- **Relative typographic sizing** (percentages, not fixed values) is a flexible, resolution-agnostic approach.
- **Czech type designer** (Martin Vacha) -- local design heritage tie for a Czech/Slovak retail brand.
- **No photography direction** is a notable gap for a lifestyle/fashion-adjacent brand.
