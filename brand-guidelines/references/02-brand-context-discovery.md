# Phase 1: Brand Context Discovery

Run this interview before drafting document content. This phase gathers the inputs needed to ground the guidelines in the brand's actual reality.

## Operating principle

- READ first, ASK second. If the user has shared materials (brief, strategy doc, existing assets, prior guidelines, website link), read them first and only ask about gaps.
- BATCH questions. Use `AskUserQuestion` to ask 2–4 related questions at a time, never one at a time. Group related dimensions.
- KNOW WHEN TO STOP. Once you have enough to draft a credible v1, stop interrogating. You can iterate.
- CONFIRM A WRITTEN BRAND SUMMARY before drafting. Send back a short "here's what I understand about your brand" summary and let the user correct it.

## Six discovery dimensions

Work through these in order. Skip dimensions where you already have data.

### 1. Identity basics

| Question | Why it matters |
|----------|----------------|
| What is the brand's full legal name and the public/trading name? | Distinguishes parent vs market-facing identity |
| What does the brand do, in one sentence? | Anchors all positioning |
| What industry / category? | Drives section emphasis (real estate → signage; SaaS → digital UI; hospitality → photography) |
| Who do they serve (B2B, B2C, both)? | Shapes voice, audience definition, application examples |
| Geographic scope (local / national / multi-market)? | Drives multilingual, multi-script, regulatory needs |
| Founded / launching when? | New launch vs rebrand changes the strategy framing |

### 2. Strategic foundation

For each item, ask: "Do you already have this defined? If yes, share it. If no, do you want to define it as part of this document, or is it out of scope?"

- **Purpose** — why the brand exists (philosophical "why")
- **Vision** — aspirational future state
- **Mission** — what they do, today, to get there
- **Values** — 3–5 named values
- **Personality** — 4–6 adjectives, ideally with "X but not Y" anti-definitions
- **Positioning statement / tagline** — distinctive promise vs competitors
- **Archetype** — optional; use only when it is strategically defined and useful

If the user has none of these defined: they need a brand strategy session before writing guidelines. Offer to either (a) defer the document, (b) draft a working strategy as a starting point and flag it as v0.1 for stakeholder review, or (c) build a visual-only document with strategy as a placeholder.

### 3. Audience and positioning

- Primary audience — demographic, psychographic, behavioral profile
- Secondary audience(s) — partners, employees, investors, regulators
- 3–5 named competitors — what makes this brand different from each?
- Category convention — what's the default look in this category? (e.g. fintech defaults to teal+black; we want to break or follow it?)

### 4. Existing assets

Ask the user to share or describe:

- **Logo** — file format(s), variants (primary, secondary, monochrome, reversed, icon-only)
- **Typography** — typeface name(s), license / source (Google Fonts, foundry, custom), weights in use
- **Color** — palette with values; ask for HEX at minimum, ideally Pantone+CMYK+RGB+HEX
- **Photography / Illustration** — existing library? mood board? stock licenses?
- **Voice samples** — website copy, ad campaigns, email, social posts
- **Graphic devices** — recurring patterns, icons, ornaments, named devices
- **Applications already in the wild** — website, packaging, signage, stationery

If the brand has NO existing assets: this is identity creation, not documentation. The skill should still work, but flag clearly that you'll be defining the system from scratch (default fonts, default palette structure, generative graphic principles) and the document will be a v0.1 to be refined as the visual direction is finalized.

### 5. Document scope

| Question | Options |
|----------|---------|
| Who will use this document? | Internal team / external partners / both / public-facing |
| What's the primary delivery format? | Screen PDF / print PDF / Figma / Notion / web microsite / DAM |
| Page tier? | Compact 20–30 / Standard 30–50 / Comprehensive 60–90 |
| Single language or multilingual? | English only / bilingual / multi-script |
| Is there a budget for custom assets? | Custom fonts / commissioned photography / illustrated icon set |
| Is this a v1 or an update? | New / update vN.x — if update, what triggered it? |
| Required compliance topics? | Accessibility (WCAG) / regulatory (FDA, FCA, GDPR) / brand-safety / ESG |

### 6. Tone of the document itself

Choose whether the guidelines should express the brand's voice or use a neutral reference register. Ask:

> Should the guidelines themselves sound like the brand — warm and chatty, opening with a greeting in the brand's own voice — or read as a neutral reference manual, in the engineering-grade register of a classic corporate identity standard?

Default to **brand voice for hybrid documents**, **neutral for compliance / partner / regulatory documents**.

## Suggested AskUserQuestion batches

Use these as starting points. Adjust based on what the user has already shared.

**Batch 1 — Basics + tier** (run first, almost always)

```
Q1: What is the brand and what does it do, in one sentence?
Q2: Industry / category?
Q3: Document tier? [Compact 20–30pp / Standard 30–50pp / Comprehensive 60–90pp]
Q4: Primary audience for the document — internal team, external partners, or both?
```

**Batch 2 — Strategic foundation** (run after Batch 1)

```
Q1: Does the brand have a defined purpose / mission / vision? If yes, share it.
Q2: How many values / pillars are defined (or do we need to draft them)?
Q3: 3–5 personality adjectives that describe the brand?
Q4: 1-line positioning or tagline — what distinguishes this brand?
```

**Batch 3 — Existing assets** (run after Batch 2 if not already shared)

```
Q1: Logo — share files (or describe variants you have)
Q2: Typography — typeface name(s) and source
Q3: Color palette — share values (HEX at minimum)
Q4: Photography library — existing, planned, or stock?
```

**Batch 4 — Tone and document personality**

```
Q1: Should the document itself sound like the brand, or be neutral reference register?
Q2: Three brands whose guidelines you'd point to as inspiration (and why)?
```

## Write-back: the brand summary

After Phase 1 ends, write a short summary back to the user — about 8–12 lines — covering:

```
Brand:                [name + one-line description]
Industry / category:  [...]
Audience:             [primary] (+ [secondary])
Strategic foundation: [purpose] / [mission] / [N values: x, y, z] / [4 personality traits]
Positioning:          [1-line distinctive promise]
Existing assets:      [logo: yes/partial], [type: name], [color: N colors with HEX], [photo: yes/no/planned]
Document scope:       [tier] / [audience] / [format] / [special requirements]
Document tone:        [brand voice / neutral / hybrid]
Open questions:       [any remaining gaps]
```

Then ask: "Does this match how you see the brand? Any corrections before I draft the document?"

DO NOT skip this confirmation step. It's the cheapest correction point in the entire workflow.

## Common pitfalls

- **User says "just use what's in the brief" but the brief is a 2-line email.** Push for more specifics. A skeleton brief produces a generic document.
- **User says "make it like Apple's"** but their brand has nothing in common with Apple. Use the comparison to extract WHAT they admire (rigor? minimalism? authority? clarity?) and apply that quality, not the visual style.
- **User has no strategy and wants to skip Phase 1.** Offer the visual-only fallback with a placeholder strategy section, v0.1 marker, and stakeholder review note; explain that the document will remain incomplete until strategy is defined.
- **User shares 50 reference brands.** Ask them to pick the top 3 with reasons. Long inspiration lists are usually a sign of unclear direction.
