# Rubric Templates

Adapt to the declared intent. Don't apply mechanically — skip irrelevant criteria, add domain-specific ones.

## By Output Type

**Written Document** — Thesis clarity, evidence quality & attribution, structure & flow, completeness, clarity for unfamiliar readers, conciseness (no filler/repetition), audience fit, actionability.

**Proposal / Pitch** — Problem definition, solution clarity, value prop (benefit to audience not author), feasibility (timeline/cost/resources), risk acknowledgment, differentiation vs. alternatives, clear ask/CTA, credibility signals.

**Code / Technical** — Correctness, edge case handling, error handling (not silently swallowed), readability, naming clarity, security (injection/exposure/hardcoded secrets), performance, documentation, dependency justification, testability.

**Plan / Strategy** — Goal specificity (measurable, time-bound), step concreteness & ownership, sequencing & dependencies, resource realism, contingency/Plan B, success criteria & metrics, stakeholder coverage, milestone timeline.

**Email / Message** — Purpose clarity (why am I reading this?), tone match, brevity, action clarity, context sufficiency, emotional awareness for sensitive topics.

**Creative Writing** — Voice consistency, engagement (hook/sustain/resolve), purpose achievement, audience resonance, originality (no clichés), pacing & transitions, concrete specificity vs. vague abstraction.

**Data Analysis** — Methodology transparency & reproducibility, data source quality & limitations, statistical validity (sample size, significance, causation vs. correlation), visualization clarity, conclusion support, alternative explanations, practical implications.

**Structured Data / Config / Schema** — Field completeness, type correctness, naming consistency, valid value ranges, referential integrity, sensible defaults, documentation/comments, example usage, migration compatibility, error state handling.

## Custom Rubric Builder

When no template fits:
1. Extract success criteria from the declared intent.
2. Add universals: accomplishes purpose, internally consistent, audience-appropriate, complete enough to be useful, clear enough to be understood.
3. Add domain-specific criteria (regulatory, technical accuracy, brand voice, etc.).
4. Prioritize by impact — rank criteria by how much they affect effectiveness.
5. Present rubric to user before validating: "Here's what I'll evaluate against — does this match what matters to you?"
